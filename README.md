# Dino Jelly · 恐龙岛

一座冒烟的火山、四种恐龙、一片会回应你的果冻海 —— 纯前端 3D 交互小品（three.js，零构建、零依赖安装）。

**▶ 在线直接玩：<https://wumingzhirencao-max.github.io/dino-jelly/>** —— 手机浏览器也能开（触屏拖拽旋转、双指缩放）。

**本地玩**：`git clone` 后双击 `index.html`（Chrome / Edge），或 `node serve.cjs` 然后开 <http://127.0.0.1:8795/>。
仓库就是完整可玩版本，运行期只用到根目录的 `.js/.css` 和 `assets/`、`models/` 里的资源，不需要装任何包。

## 在线体验（GitHub Pages）

线上跑的是 `main` 分支的静态托管（Source = `Deploy from a branch: main / (root)`）。两点差异要知道：

- 静态托管**没有后端**，所以两块调参面板读的是仓库里的 `tuning.json`（当前这组就是作者调好的参数），
  拖滑杆当场生效、刷新回原值；点「设为默认」只在本地 `node serve.cjs` 下才会写盘。
- 想换掉线上默认值：本地调好 → 点「设为默认」→ 提交并推送 `tuning.json` → Pages 一分钟重建。

实验室面板里的**天气滑杆**：中间是多云（保持原样），**往左越下越大雨**（天空转灰、光照变暗、雨点打在水面上冒涟漪），**往右越来越晴**（更亮、天更蓝、云更白）；雨天夜里也成立。
大雨档还会**打闪**（平均十几秒一次，画面短暂亮起、伴随闷雷；雷声跟着顶部「海洋音效」开关走）。**鱼群也看天气**：雨越大越往深处压、越贴着岛缘躲、扎得越紧、游得越快；回到多云就精确回到原样。

四只动物之间也会互动（`pet-life.js`）：点任一物种按钮它会打招呼、**离得最近的那只也会转头看过来**；
投放小鱼时翼龙有几率俯冲抢走，小紫若先到就先吃到；小紫游到岸边时腕龙会走到那一侧**低头探水**、
迅猛龙沿沙滩伴游。面板最下面一行显示"刚刚：…"的最新互动。

小紫会**长大**：成长点 = 你亲手喂它吃掉的鱼 + 它自己猎到的鱼，跨过 3 / 8 / 16 点换一个阶段
（幼生期 → 幼体期 → 亚成体 → 成体）。每次升阶体型变大、紫色变深，并依次长出背鳍、尾鳍、侧腹发光点；
面板第一行显示「阶段 · 成长 x/y」，升阶会提示"小紫长大了：××"。它潜到水下追鱼时会真的**扑咬**：
贴到两单位内就冲刺抬头咬中（咬空 2.2 秒放弃，回去巡游）。阶段存在本机存档里，刷新页面仍在。

「投喂小鱼」现在**水面和小岛都能投**：点海水是小紫的鱼群，点岛面则会撒小鱼干——
最近的陆地恐龙（迅猛龙 / 腕龙 / 翼龙）会走过来一颗颗吃掉，边吃边冒爱心，吃完再走回原位。
陆地动物始终待在干沙范围内（世界半径 4.0 以内），不会走进海里。

## 天空与云

场景是「一整块通透的玻璃水块浮在淡蓝天空里」，天空是渐变天穹（`sky.js`），四周有低多边形云在缓慢漂移，
方块下方只有一小片柔和接触阴影。点「☀ 白昼 / ☾ 夜晚」时天空与云一起变色。
（3.28 曾在岛正上方加过 4 朵小白云，**3.41b 已按你的要求删掉**，现在天上只有远处那 12 朵。）

翼龙在岛的上空自由盘旋：横向能飞到大半个水块的范围，高度上也会自己爬升与滑翔
（`island.js` 里的路径由两条不同频率的正弦交叉给出，所以不会一直绕同一个圈）。

水体侧壁只画朝外的一面（`FrontSide`），所以透过水面**看不到远端内壁**那条深色带；
远端的掠射天光反射也压低了（`envMapIntensity .18`），因此水面从边缘到内部是**一整片**，
不会再出现"外圈浅色带 + 内圈界线"的分层感。

水下是一套程序生成生态（`seabed.js`）：冷灰礁石、分枝珊瑚／海葵／盘状珊瑚（6 色高饱和）、
海带与海草、上升气泡泉（一个 InstancedMesh），外加 34 条彩色小鱼。
水面不透明度 0.60，是这个"看得到水下"和"果冻体积感"之间的平衡点（试过 0.50 / 0.68）。

岛体不是浮在水上的：可视岛体是一层程序生成的沙坡，它的沙滩外缘落在世界半径 5.4–5.8、y≈-0.3，
而这片沙坡还会**继续往外多长两圈**（同一 `u=r/border` 参数、同一材质），一路扎到海床剖面以下——
于是**岛基和海床是同一片地形接起来的**，水下平视看不到岛底悬空，也没有围着一圈平台或圆片
（最早那块平放在 y=-.5 的 `shoal` 圆片已删除，浅滩绿调改烘进海床顶点色）。
海床本身保持纯泻湖剖面、不为岛做任何抬高；「水深」滑杆与水色照旧，所以水面观感没有跟着变。

**水深**滑杆控制水体的深度渐变。水色由真实海底地形驱动：水面每个顶点都带一份 0–1 的水深读数，
**浅的地方（岛边泻湖）更亮更透、能看清沙床和珊瑚，深的地方（方块外缘）更暗更实**，像真海一样。
珊瑚顶端水浅所以更亮。0 档 = 均匀单色，100 档 = 最强调的深浅对比（默认 65）。

另外有两层程序生成的贴图：水面之上单独叠一层**水皮**（自己一张水纹贴图，透明度按水深递增，
深处变实并把残留的海床线盖住）；海底的颜色由一张**深浅贴图**给出（按真实地形插值 + 斑驳 + 沙纹），
顶点色只保留明暗斑驳。

这两张贴图现在由本机 **Photoshop** 生成（`assets/water-skin.png`、`assets/seabed-depth.png`，
脚本 `_baseline/ps-textures.ps1`）。水纹是"单色噪点 + 长距离动感模糊 + 正片叠底"做出的稀疏流动带；
海底那张存的是灰度深浅图，沙色→深色在着色器里映射，所以调色板不用回 PS 重导。
两张 PNG 缺失时会自动退回代码里的 canvas 版本。上一版水纹留档在 `assets/water-skin-v1-cloudy.png`。

### 小紫的成长能力
成长点（投喂次数＋捕食次数）达到 0 / 3 / 8 / 16 时，小紫依次进入幼生期、幼体期、亚成体、成体。游速、追球速度、顶球力度和潜水持续时间随阶段提高；所有阶段都能探索全水域。避岸和边界距离随体型调整。旧存档无需转换。

### 鱼群反应
每条鱼的巡游速度略有不同，并缓慢变化。连续投喂会短暂提高附近鱼群的抢食速度；小紫潜到附近、追捕时，鱼会加速向不同方向散开。危险消失后逐渐重新巡游。

每条鱼还会**自己找事做**（闲逛）：每隔 4–12 秒挑一个新的目的地，转向是渐进的、不会一帧掉头。投喂小鱼时它们会**一颗颗地追那些鱼食**——
游到跟前、浮上水面、用嘴碰到才吃掉（吃了会冒个小涟漪），而不是围着投食点转圈。**右键牵引海水会把附近的鱼惊散**（脉冲约 0.85 秒淡出后重新巡游）。
这几条行为是从 `yutang` 那个锦鲤池项目提取出来的行为库移植进 `ocean-life.js` 的，回归检查 `check-fish-school.cjs`。
