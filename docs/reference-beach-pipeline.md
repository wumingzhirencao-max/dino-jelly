## 与我们（three.js 恐龙岛）的对应关系

**已有**：02 浅水模拟（`island.js` 水面 `PlaneGeometry(150,150,110,110)`，比它的 256² 稀）；
04 沙层剖面（`island.js:146` "tabletop cutaway"）；06 焦散（`island.js:177`、
`art-direction.js:17`，而且 `art-direction.js:14` 已经把 `attribute float aDepth`/`vBathy` 接进 shader，
只是"深浅分色"还压着：`uDepthMix=.55`、焦散强度只有 `.012`）；09 天空反射（`art-direction.js:10`
`envMapIntensity=.45`，3.39 那次球面环境贴图已铺好）；10 碎浪白水（`shoreDistance` 驱动的 surf）；
13 浪峰白条（**3.40b 按用户要求已关**：`island.js:189` 注释「取消右键点下去那圈海浪贴图」，
`froth*=uFoam` 里 `uFoam=crestStrength`）；12 软岸线（部分：`foam` 环 `island.js:14`
`RingGeometry(10.6,11.1)`，`#b6eae1`/opacity .35）。

**缺的四样（也正是"风格化沙滩"最容易被一眼认出来的特征）**：
1. **湿沙带**（05）——目前沙色是 `island.js:5` `#deb986`（后续 `148` 行 scale 后改 `#e9d2a2`）**单一色**，
   水线附近没有变深；这条是"水刚过的沙子"最直观的信号。
2. **泡沫画在水下**（14）——"岸边残沫与泡沫投影"，泡沫要在水面的**下方**、被水体染色。
3. **软岸线**（12）——按"水深几厘米"做程序化过渡，而不是按半径硬切（`shoreMask` 现在是 `smoothstep(6.1,7.3,length(vSea.xz))`）。
4. **浪峰白条与碎浪白水的分离**（13 vs 10）——我们两条都收在 `uFoam` 一个开关里（3.40b 一起关掉了），
   视频是分开处理、可各自调。

**接入点（真要动手时的落点）**：`island.js:173-196`（第二份 shader，最终生效）+
`art-direction.js:14-51`（第一份）——**两份必须同时改**（本项目硬约束：后写的会覆盖先写的）；
沙层在 `island.js:5-10` 与 `island.js:148`；水深/水线信息用 `art-direction.js:14` 已有的 `aDepth`（`vBathy`）。
