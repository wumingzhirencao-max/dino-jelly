## 4. 这轮挖出并修掉的两个**旧** bug（值得知道，因为同类还可能再有）

1. **一开「海洋音效」主循环就断**（3.31 就埋着）：`initAudio()` 里 `…;const buffer=…` 的逗号声明把 `filter` 也声明成了**局部** `const`，外层 `filter` 永远是 `null` → `update()` 每帧 `Cannot read properties of null (reading 'frequency')`。主循环异常不冒泡到页面事件，所以要**开音效**才走到、一直没人发现。
2. **34 条鱼常年被顶在水面**：`goalY` 三元式的兜底分支在**不投喂**时也走 `.05`，鱼层等于失效（这也是雨天压深本来会"看不出来"的原因）。改成不投喂时回落到各自的 `homeY`。

## 7. 改这块代码时的坑（血泪，按踩到的顺序）

1. **跨模块的输入只留一个真源，且"现算"不"存副本"**。这轮我一开始在 `weather.js` 和 `ocean-life.js` 各存了一份雨量，两边各写各的 → 出现"滑杆 50 却按 0 算""同一 tick 里两个 getter 报出互相矛盾的值"，查了 20 多个探针才定位。最终形态：`weatherLife.rain` 是纯函数（由滑杆位置现算），别人每帧从它读。
2. **别在同一个函数里既覆盖又读取同一状态**。`applyLights()` 若先 `state.hemiSky.copy(hemi.color)` 再按 flash 改 `hemi.color`，下一帧就把"被闪电染白的颜色"当基准吃进去 → 跨帧漂移。颜色基准只在初始化时快照一次。
3. **闪电必须按绝对时间衰减**（`performance.now()`），不能只用 `update(dt,t)` 的 dt——暂停（dt=0）时旧写法会把画面卡在半亮。
4. **滑杆 `id` 会生成同名 DOM 全局**（3.31 的坑）：新控件 id 先查是否与要暴露的全局同名。
5. **测"某输入真的改变了行为"必须每档固定同一颗随机种子**再量；否则噪声（本机约 0.15）比要测的效果还大。但**播种救不了"群心/相位"类指标**——那种只做遥测。
6. **验音频别只看返回值**：用 `addInitScript` 把 `AudioContext` 换成子类，`destination` 指向一个**真 AudioNode 中转站**（`master → hop → realDest`，analyser 从 hop 抽头）再 `getFloatTimeDomainData`。**别用普通对象/Proxy 冒充 `destination`**——原生 `connect` 只认真 AudioNode，会 `Overload resolution failed`。
7. **PowerShell 读写带中文的源文件会把注释变成 GBK 乱码** → 一律用编辑/写入工具，别用 `Get-Content | Set-Content` 往返。
8. 改 `.js` 先 `node --check`；动布局/相机补跑 `check-embed-pane` + `check-mobile-layout`。
